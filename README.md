# Visual Design Challenge: Budget Tracker (Week 3)

## Project Overview
This project is an enhancement of the Personal Budget Tracker interface, focusing strictly on visual design using CSS. Without altering the underlying functional HTML structure, the visual presentation was transformed using intentional color schemes, modern typography, enhanced table and form aesthetics, and structural layout using the CSS Box Model.

---

## Key Design Enhancements

### 1. Intentional Color Palette
- **Background (`#f4f6f8`):** Provides a light gray canvas for high contrast against content cards.
- **Primary Accent (`#2563eb`):** Applied to primary headings and main action buttons to draw attention to key interactive areas.
- **Dark Slate Header (`#1e293b`):** Establishes structure and clear boundary separation for table data header fields.
- **Alert/Delete Accent (`#ef4444`):** Clear visual mapping for destructive actions.

### 2. Custom Typography
- **Headings (`Poppins`):** Uses Google Fonts' *Poppins* font family to deliver crisp visual anchors for main sections (`h1`, `h2`, table headers).
- **Body & Inputs (`Inter`):** Uses Google Fonts' *Inter* family to maximize readability for standard text, input field entries, and row items.

### 3. Form and Table Refinements
- **Form Controls:** Added padding inside `input` and `select` boxes, soft borders, border-radius rounding, and focus outlines (`:focus`) for feedback on direct user interaction.
- **Table Formatting:** Formatted with `border-collapse: collapse`, cell padding, contrasting headers, and alternating row background colors (`:nth-child(even)`) for clean row tracking.

### 4. CSS Box Model Application
- **Card-Based UI:** Applied consistent `padding: 24px`, light border borders, `border-radius: 12px`, and subtle drop shadows (`box-shadow`) to group related elements into visual card containers.
- **Spaced Layouts:** Used `margin-bottom: 24px` on container sections to maintain visual rhythm and separation across the application.
